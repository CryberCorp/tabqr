安装 TabQR

像应用一样使用 TabQR：独立图标和窗口，离线也能用。

请在浏览器中打开此页面以安装 TabQR。

  1. 在 Safari 中轻点“共享”（或先轻点 ···，再轻点“共享”）。
  2. 选择“添加到主屏幕”。
  3. 保持“作为网页 App 打开”开启，然后轻点“添加”。
  1. 打开浏览器的 ⋮ 菜单。
  2. 选择“安装应用”或“添加到主屏幕”。
  3. 确认后，TabQR 会出现在你的应用中。
  • Safari：“文件”>“添加到程序坞”。
  • Chrome 或 Edge：点击地址栏中的安装图标。
  • Chrome 或 Edge：点击地址栏中的安装图标，或菜单 >“安装 TabQR”。
  • Windows 版 Firefox：点击地址栏中的“将标签页添加到任务栏”。
