TabQR est une extension Chrome qui crée des codes QR à partir d’une adresse web ou d’un texte fourni par l’utilisateur. Cette politique explique quelles informations l’extension utilise et comment elles sont traitées.

## Informations traitées par l’extension

- **Adresse de l’onglet actif :** lorsque vous ouvrez TabQR, l’extension lit l’adresse de l’onglet actif pour pouvoir en générer un code QR. Elle ne parcourt pas le contenu de la page. Le texte d’une page n’est traité que si vous le sélectionnez et demandez explicitement sa création en QR code.
- **Texte fourni par vous :** le texte saisi dans TabQR ou le texte que vous sélectionnez puis envoyez à TabQR via le menu contextuel est utilisé pour créer le code QR. Ce texte peut contenir une adresse e-mail, un numéro de téléphone ou toute autre information que vous choisissez d’encoder.
- **Préférences :** la couleur du code QR, sa couleur de fond et le format d’exportation choisi sont enregistrés localement dans le navigateur.

## Traitement et stockage

La génération du code QR et la personnalisation s’effectuent localement dans votre navigateur. TabQR ne transmet pas ces informations au développeur et l’extension n’utilise ni outil d’analyse ni publicité.

Si vous utilisez le menu contextuel, le texte sélectionné est temporairement enregistré dans le stockage local de l’extension afin de le transférer à sa fenêtre. Il est supprimé dès que cette fenêtre le récupère. Si la fenêtre ne peut pas s’ouvrir, le texte peut rester dans ce stockage jusqu’à sa prochaine récupération ou jusqu’à la suppression des données de l’extension.

Lorsque vous ouvrez l’aperçu agrandi, le texte, la couleur et la couleur de fond sont placés dans l’adresse de cette page interne de l’extension afin de restaurer l’aperçu après actualisation. Votre navigateur peut conserver cette adresse dans son historique local. Les préférences de couleur et de format restent enregistrées localement jusqu’à leur suppression ou la désinstallation de l’extension.

## Actions que vous choisissez

Si vous choisissez de copier le contenu, TabQR le place dans le presse-papiers de votre appareil. Si vous téléchargez un code QR, le fichier est créé à la demande dans votre navigateur. Dans l’aperçu agrandi, cliquer sur un lien, une adresse e-mail ou un numéro de téléphone peut ouvrir le site web ou l’application correspondante ; le traitement ultérieur relève alors du service ou de l’application que vous choisissez.

## Partage et transmission

L’extension ne transmet pas le contenu du QR code, l’adresse de l’onglet ou le texte sélectionné à un serveur ou à des tiers. Aucune donnée n’est collectée par le développeur via l’extension.
