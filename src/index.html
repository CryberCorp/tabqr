Install TabQR

Use TabQR like an app: its own icon and window, even offline.

Open this page in your browser to install TabQR.

  1. In Safari, tap Share (or ···, then Share).
  2. Choose “Add to Home Screen”.
  3. Keep “Open as Web App” on, then tap Add.
  1. Open the browser menu ⋮.
  2. Choose “Install app” or “Add to Home screen”.
  3. Confirm: TabQR joins your apps.
  • Safari: File > “Add to Dock”.
  • Chrome or Edge: click the install icon in the address bar.
  • Chrome or Edge: click the install icon in the address bar, or menu > “Install TabQR”.
  • Firefox on Windows: click “Add tab to taskbar” in the address bar.
